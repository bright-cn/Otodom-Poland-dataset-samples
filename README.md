## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `timestamp` | 房源信息被记录到数据集中的日期和时间。 |
| `title` | 房源的简短标题，通常会突出其主要特点。 |
| `price` | 房源的挂牌价格，以波兰兹罗提（PLN）计价。 |
| `market` | 表示市场类型，例如一级市场或二级市场。 |
| `surface` | 房产的总居住面积，以平方米为单位。 |
| `location` | 房产的完整地址，包括街道、城市和省份。 |
| `remote_support` | 表示房源是否为潜在买家提供任何形式的远程支持。 |
| `lighting` | 房产自然或人工照明设施的详细信息。 |
| `advertiser_type` | 说明房源由中介机构还是私人卖家发布。 |
| `description` | 房产及其特点的详细描述。 |
| `no_of_rooms` | 房产的房间总数。 |
| `form_of_property` | 房产的类型或分类，例如公寓或独栋住宅。 |
| `url` | 可查看完整房源信息的网址。 |
| `is_for_sale` | 表示房产目前是否在售的布尔值。 |
| `posting_id` | 数据集中房源的唯一标识符。 |


## 应用场景

### 1. 房地产市场分析
分析波兰房地产市场的趋势，以发现投资机会和价格随时间的变化。

### 2. 房地产中介竞争对手分析
房地产中介机构可以利用这些数据与竞争对手进行对标，并优化房源发布策略。

### 3. 城市发展研究
研究人员可以研究城市发展对不同地区房产价值和住房供应情况的影响。
